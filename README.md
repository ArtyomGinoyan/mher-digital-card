# Mher QR site

Статичная страница-визитка (contact card) + CV в формате PDF.
Почти без JavaScript — один маленький файл `intro.js` (~10 строк, без зависимостей и
сторонних вызовов) отвечает только за необратимое скрытие заставки, всё остальное —
чистый HTML/CSS. Никакой аналитики, никаких сторонних сервисов.

## Файлы

- `index.html` — заставка + армянская карточка (используется по умолчанию, на неё указывает QR-код)
- `en/index.html`, `de/index.html`, `ru/index.html` — версии на английском, немецком и русском (у каждой своя переведённая заставка)
- `style.css` — общие стили для всех языковых версий (светлая/тёмная тема)
- `intro.js` — единственный скрипт на сайте (см. "Дизайн" ниже)
- `cv.pdf` — полное резюме (на английском, как в исходном документе), скачивается по кнопке на любой языковой версии
- `photo.png` — фото (извлечено из исходного PDF-резюме, 250×250)
- `robots.txt` — запрещает поисковикам индексировать страницу (см. "Приватность" ниже)

## Дизайн

Bento-сетка плиток разного размера на светлом бело-голубом фоне (в духе normed.am),
со стеклянными (glassmorphism) карточками и синим акцентом. Живые детали: мини-ЭКГ в
плитке специальности, плитка опыта переворачивается (на мобильном — чередуется
автоматически, без наведения), плитка языков показывает уровень владения во
всплывающем окошке.

**У каждой языковой страницы своя заставка** с именем и переводом роли, плюс
переключатель языка прямо на ней (не нужно сначала её проходить, чтобы сменить язык).
Клик или скролл — оба сразу открывают карточку, и оба необратимы: заставку больше не
показывают повторно, назад к ней не вернуться.

Именно необратимость — единственная причина, по которой на сайте вообще есть
JavaScript. Заставка сама по себе — обычный блок в начале страницы (не плавающий
слой), поэтому скролл и так естественно "пролистывает" её без всякого кода. Но
*сделать так, чтобы после этого нельзя было проскроллить обратно* — задача
принципиально не для CSS: CSS умеет описывать только текущее состояние (`:checked`,
`:target`, позицию скролла и т.п.), а не "помнить", что что-то произошло в прошлом.
Как только условие снова меняется (проскроллили назад), CSS-эффект просто
откатывается. Постоянную память нужно явно записать — этим и занимается `intro.js`:
при первом скролле или клике добавляет классу `<html>` `intro-dismissed`, дальше CSS
прячет заставку по этому классу насовсем. Без JS (например, отключён в браузере)
сайт не ломается — просто заставка снова становится обратимой (что не критично, это
чисто декоративный первый экран).

**Тёмная тема** переключается вручную (значок ☀/☾ в углу) или следует системной теме
устройства по умолчанию — реализовано чистым CSS (чекбокс + `:has()`), без единой
строчки JavaScript.

**На мобильном** при скролле внизу экрана закреплена компактная кнопка "Скачать CV".
Есть отдельные стили для печати (`@media print`) — при печати страница становится
чёрно-белой и убирает декоративные элементы.

Переключение языков — это просто обычные ссылки на соседние `index.html`.

Все четыре страницы дополнительно подключают шрифты **Bricolage Grotesque** (основной
крупный шрифт) и **Noto Sans/Serif Armenian** (чтобы армянский текст не превращался в
"квадратики" на устройствах без установленных армянских шрифтов) с Google Fonts — это
единственный внешний ресурс на сайте. CSP везде точечно разрешает только
`fonts.googleapis.com` и `fonts.gstatic.com`.

## Как посмотреть локально

Проще всего просто открыть `index.html` двойным кликом — страница не использует JS/fetch,
так что откроется корректно прямо из файловой системы (`file://`).

Если хотите смотреть как на "настоящем" сервере (рекомендуется перед деплоем, чтобы
проверить пути и заголовки так же, как это будет на GitHub Pages):

```powershell
cd "C:\Users\User\Desktop\Mher QR site"
python -m http.server 8000
```

и открыть `http://localhost:8000` в браузере.

## Как задеплоить на GitHub Pages

1. Создать новый **публичный** репозиторий на GitHub (например `mher-cv`)
2. В этой папке:
   ```powershell
   git init
   git add index.html en de ru style.css intro.js robots.txt cv.pdf photo.png .gitignore README.md
   git commit -m "Add CV contact card"
   git branch -M main
   git remote add origin https://github.com/<username>/mher-cv.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source → Deploy from a branch → main / (root)**
4. Через пару минут сайт будет доступен по адресу `https://<username>.github.io/mher-cv/`
5. Эту ссылку и зашивайте в QR-код (например через qrcode-monkey.com)

## О безопасности и приватности (важно прочитать)

Эта страница публикует реальные контактные данные (email, телефон), поэтому применены
следующие меры:

- **Строгий Content-Security-Policy** (`default-src 'none'`) — по умолчанию запрещено
  всё, кроме явно перечисленного. Единственное разрешение для скриптов —
  `script-src 'self'`, то есть выполнится только `intro.js` из того же источника;
  инжектированный (например, через XSS) сторонний скрипт браузер не запустит, даже
  теоретически. Инлайн-скриптов в HTML нет вообще — только внешний файл.
- **`X-Content-Type-Options: nosniff`** — браузер не будет пытаться угадывать тип файла.
- **`noindex, nofollow`** (и `robots.txt`) — страница не индексируется поисковиками.
  Она доступна только тем, у кого есть прямая ссылка или QR-код, а не всем, кто ищет
  "Mher Mkrtchyan" в Google. Это снижает риск, что email/телефон соберут спам-боты.
- **Дата рождения и гражданство из исходного CV сюда намеренно не перенесены** — на
  публичной контакт-карточке они не нужны, а лишняя личная информация в открытом доступе
  повышает риск социальной инженерии / кражи личности. Полная версия с этими данными
  остаётся только внутри `cv.pdf`, который скачивается по прямому клику, а не
  дублируется в самом HTML.
- Единственный скрипт (`intro.js`) — свой, того же происхождения, без зависимостей,
  ничего никуда не отправляет, только читает/пишет один CSS-класс. Никакого стороннего
  JS, шрифтов с CDN (кроме Google Fonts, см. выше), аналитики или трекеров.

**Важно понимать про GitHub:** после `git push` в публичный репозиторий email, телефон
и содержимое `cv.pdf` становятся общедоступными и остаются в истории git даже если
вы позже удалите файл или сделаете репозиторий приватным задним числом — история
коммитов может быть закэширована сторонними индексаторами GitHub. Публикуйте только то,
чем действительно готовы делиться публично.
